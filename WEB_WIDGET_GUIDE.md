# 🌐 Инструкция по установке через Web Widget (Способ 2)

Этот способ воспроизводит 100% аутентичные эффекты **Apple Liquid Glass** (настоящее размытие `backdrop-filter: blur`, световой блик `sheen` и преломление света `refraction rim`) прямо из HTML-файла.

---

## Вариант А: Через приложение «Web Widget» (Рекомендуется)
1. Открой **Google Play** на Nothing Phone и установи бесплатное приложение **Web Widget** (автор: *An wave co.* или аналогичное *HTML Widget / MetaWidget*).
2. Скачай из этого репозитория файл `widget.html` на телефон.
3. Добавь на рабочий стол Nothing OS виджет приложения **Web Widget** размером **2×1**.
4. В настройках виджета:
   * **URL / Source**: выбери локальный файл `widget.html` (либо укажи ссылку: `https://cernokalskijgerman-arch.github.io/widjet/widget.html`).
   * **Background**: включи `Transparent` (Прозрачный).
   * **Update Interval**: `1 minute` (виджет внутри сам обновляется каждую секунду через JavaScript).
5. Нажми **Готово** / Сохранить.

---

## Вариант Б: Через приложение «Hermit • Lite Apps»
1. Установи **Hermit** из Google Play.
2. Создай новый Lite App, указав ссылку `https://cernokalskijgerman-arch.github.io/widjet/widget.html`.
3. Добавь виджет Hermit на рабочий стол размером 2×1.
