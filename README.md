# 🔴 Nothing Phone (3a) Pro — Minimal Schedule Widget (Liquid Glass)

Минималистичный виджет школьного расписания для **Nothing Phone (3a) Pro**, спроектированный по дизайн-системе **Apple Liquid Glass** с фирменным стилем **Nothing OS** и акцентом **Nothing Red (`#D71921`)**.

---

## ⚡ Особенности виджета
* **Форм-фактор 2×1:** Занимает ровно 2 позиции на экране (как 2 иконки приложений в ряд).
* **Ничего лишнего:** Только название предмета, кабинет и время звонков (`09:00 – 09:40`). Без ФИО учителей и лишнего текста.
* **Умные перемены:** Во время урока отображается текущий урок. Как только звенит звонок на перемену — виджет **сразу показывает следующий урок**, а точка статуса загорается фирменным красным Nothing Red.
* **Liquid Glass:** Настоящий эффект матового стекла (`blur(26px) saturate(185%)`), световой скос кромки **Refraction Rim** (135°) и блик **Specular Sheen**.

---

## 🚀 Как установить на Nothing Phone (Выбери способ)

### 🥇 Способ 1: Через KWGT (Рекомендуется для Android / Nothing OS)
Самый нативный способ для Android, не расходует батарею и обновляется системой:

1. Установи из Google Play приложение: **KWGT Kustom Widget Maker**.
2. Добавь на рабочий стол Nothing OS виджет KWGT размером **2×1**.
3. Нажми на добавленный виджет и скопируй готовые формулы из файла инструкции:
   👉 **[Открыть пошаговую инструкцию по KWGT (KWGT_GUIDE.md)](KWGT_GUIDE.md)**

---

### 🥈 Способ 2: Через Web Widget (Быстрый запуск HTML)
Идеально передает 100% эффекты размытия Liquid Glass:

1. Установи из Google Play бесплатное приложение: **Web Widget** (или *HTML Widget / MetaWidget*).
2. Скачай файл **`widget.html`** из этого репозитория на телефон.
3. Добавь виджет **2×1** на рабочий стол и укажи в настройках файл `widget.html` (фон — Прозрачный).
   👉 **[Открыть инструкцию для Web Widget (WEB_WIDGET_GUIDE.md)](WEB_WIDGET_GUIDE.md)**

## 📂 Структура файлов репозитория
* **`widget.html`** — чистый автономный 2×1 виджет Liquid Glass для телефона.
* **`index.html`** — интерактивный симулятор времени и расписания в браузере (можно тестировать любые дни и перемены).
* **`schedule.json`** — данные расписания в структурированном виде.
* **`KWGT_GUIDE.md`** — инструкция и готовые формулы для KWGT.
* **`WEB_WIDGET_GUIDE.md`** — инструкция для Web Widget.
